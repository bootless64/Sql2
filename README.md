# Database Laboratory II

This repository contains practical exercises, assignments, and projects for the **Database Laboratory II** course as part of my Bachelor's degree in Computer Software Engineering.

## Technologies

- **MySQL** – Database management and SQL queries
- **LAMPP** – Local development environment
- **SQL** – Database creation, management, and manipulation



## Course Topics

- Database creation and management
- SQL queries and commands
- Tables, relationships, and constraints
- Data manipulation (INSERT, UPDATE, DELETE)
- Data retrieval (SELECT, JOIN, Subqueries)
- Practical database development using MySQL and LAMPP

## Purpose

The goal of this repository is to document my learning progress, organize course materials, and keep track of practical exercises and assignments throughout the semester.
